# Esports Match Telemetry – Big Data ETL Pipeline

End-to-end batch processing pipeline built with **Hadoop MapReduce (Java)**, **Apache Hive**, and orchestrated via **Apache Airflow**. The project processes raw esports match logs and player metadata to compute hero-level performance metrics per player.

## Architecture & Data Flow
1. **Ingestion (HDFS):** Raw match results (`datasource1/matches*.csv`) and player profiles (`datasource4/players.csv`).
2. **MapReduce (`src/MapReduceApp.java`):** 
   - **Mapper (`EsportsMapper`):** Sanitizes CSV inputs, splits multi-value hero strings (`;`-delimited), and emits `(player_id, hero_name)` pairs with match stats.
   - **Combiner & Reducer (`EsportsCombiner` / `EsportsReducer`):** Pre-aggregates and computes total `wins`, `draws`, `losses`, and `dominant_wins` (wins where `kills > deaths`).
3. **Data Warehouse (`hive.hql`):** Joins aggregated MapReduce output with `players.csv` metadata and formats the final dataset as NDJSON (`JSON Lines`).
4. **Orchestration (`projekt1.py`):** Apache Airflow DAG managing directory cleanup, conditional execution (`BranchPythonOperator`), MapReduce/Hive jobs (`BashOperator`), and output verification.

---

## Project Notes & Structure

* **Dataset Scope:** This repository includes a representative subset (`matches00.csv` to `matches10.csv` + `players.csv`) in `data/input/` to keep the repository lightweight and testable. The pre-computed artifact in `sample_output/output6.json` was generated by processing the complete, full-scale dataset on a multi-node Hadoop cluster.
* **Orchestration Workflow:** The Apache Airflow DAG (`airflow/dags/projekt1.py`) follows the infrastructure and structural template provided for this academic/engineering workflow, while the core data processing logic (`MapReduceApp.java` and Hive ETL queries) was custom-implemented.

Quick Start (Docker Hadoop Cluster)
Copy the repository into the Hadoop master container:

Bash
docker cp ../esports-bigdata-pipeline bigdata25-master-1:/home/hadoop/
Inside the master container, run the automated build & HDFS setup script:

Bash
cd ~/esports-bigdata-pipeline && ./setup_on_master.sh
Trigger the project1-workflow DAG in Apache Airflow (http://localhost:8080) with input_dir set to /tmp/input.
